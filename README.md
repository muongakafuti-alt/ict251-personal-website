
# ICT251 Interactive Personal Website

## About the Website
This is my personal website developed for the ICT251 Web Technologies Activity 3 assignment. It presents information about me, my hobbies, my learning plan, my projects and skills, photos, media, and contact details.

## Technologies Used
- HTML for webpage structure
- CSS for styling and responsive design
- JavaScript for interactive features

## JavaScript Features
- Contact form validation and preview
- Photo gallery viewer
- Theme switcher
- Study hours calculator

## Testing
The website is tested using Live Server and a web browser. The contact form and interactive features are checked to ensure they work correctly.

## Source Code
This repository contains the HTML, CSS, JavaScript, images, and media files used by the website.
